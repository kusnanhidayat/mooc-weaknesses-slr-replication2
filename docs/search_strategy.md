# Search Strategy

| Item | Value |
|---|---|
| Database | Scopus (Elsevier) |
| Date of search | 4 May 2026 |
| Search field | Article title, Abstract, Keywords (TITLE-ABS-KEY) |
| Search terms | "MOOC" AND "Weaknesses" |
| Filters | Language = English; Source type = Journal; Publication stage = Final |
| Year filter | None in query (scope 2006–2025 applied at eligibility; all records fell within 2013–2025) |
| Document-type filter | None in query (handled at eligibility stage) |
| Records returned | 26 (24 articles, 1 review, 1 retracted article) |

## Exact advanced query

```
TITLE-ABS-KEY ( "MOOC" AND "Weaknesses" )
AND ( LIMIT-TO ( LANGUAGE , "English" ) )
AND ( LIMIT-TO ( SRCTYPE , "j" ) )
AND ( LIMIT-TO ( PUBSTAGE , "final" ) )
```

## Rationale

- "MOOC" identifies the learning model; "weaknesses" identifies the evaluative
  focus, as used in SWOT/SWOC evaluations of MOOCs.
- Near-synonyms (challenge, barrier, limitation, difficulty, disadvantage,
  learner experience) were deliberately not included, favouring precision over
  recall. This is reported as a limitation of the review.
- Window 2006–2025: starts two years before the first course labelled a MOOC
  (2008) and ends with the last complete year before the search.
